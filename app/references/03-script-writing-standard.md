# 03 — 剧本写作规范 (Script Writing Standard)

## 1. 格式规范

### 1.1 场景头
```
场景编号: 1
地点: 内景 - 张三家中 - 客厅
时间: 日
```

### 1.2 节拍 (Beat)
每个场景由1-3个节拍组成：
- beat_phase: 节拍阶段（setup/confrontation/resolution）
- description: 场景描述
- emotion_marker: 情绪标记
- conflict_type: 冲突类型

### 1.3 对话 (Dialogue)
```
角色: 张三
台词: "我不会让你得逞的。"
动作指示: （紧握拳头，目光坚定）
```

### 1.4 付费墙标记
- is_paywall: true/false
- 付费墙前：建立悬念和期待
- 付费墙后：兑现爽点和高潮

## 2. 写作禁忌
- 禁止大段旁白（改用对话和动作）
- 禁止角色自言自语解释剧情
- 禁止跳过关键转折
- 禁止角色行为前后矛盾
- 禁止无意义的场景填充

## 3. 对话规范
- 每句对话不超过30字
- 对话必须推进情节或揭示角色
- 避免信息倾倒式对话
- 对话风格与角色性格匹配

## 4. 场景规范
- 每场景1-3个节拍
- 场景转换需有逻辑连接
- 避免连续3个以上静态场景
- 每集至少1个动态冲突场景
