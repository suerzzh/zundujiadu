# 02 — 分集架构方法 (Episode Architecture Method)

## 1. 核心原则
每集必须是一个完整的叙事单元，同时是整体叙事的有机组成部分。

## 2. 分集策略

### 2.1 集数规划
- 短篇（3-10章）：1章1集
- 中篇（10-30章）：1-2章1集，合并相关章节
- 长篇（30+章）：按故事弧线分组，每弧2-5集

### 2.2 单集结构
每集必须包含：
- **开场钩子**（前30秒）：制造悬念或展示冲突
- **发展段落**（主体）：推进情节、深化角色
- **转折点**（中后段）：改变局势的关键事件
- **结尾钩子**（最后30秒）：留下悬念，驱动下一集

### 2.3 节奏控制
- A线（主线）：每集必须推进
- B线（副线）：可跨集发展
- C线（暗线）：长线伏笔，偶尔暗示

### 2.4 集间衔接
- 上一集结尾钩子 → 下一集开场回应
- 角色状态在集间保持连续
- 道具/线索在集间传递

## 3. 输出格式
分集规划以 JSON 格式输出，每集包含：
- episode: 集号
- title: 集标题
- logline: 一句话梗概
- source_chapters: 对应原文章节
- key_events: 关键事件列表
- hooks: 钩子设计
- satisfaction_points: 爽点设计
