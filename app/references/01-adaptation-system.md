# 01 — 改编分析系统 (Adaptation Analysis System)

## 1. 核心目标
将小说原文转化为结构化改编分析，为后续分集规划提供决策依据。

## 2. 分析维度

### 2.1 题材识别
- 末世重生：重生/穿越/末世/系统/金手指
- 玄幻：修仙/武道/天劫/灵根/境界
- 女频：宫斗/甜宠/虐恋/逆袭/双洁
- 网文通用：爽文/系统流/无限流/快穿

### 2.2 频向判定
- 男频：升级打怪、装逼打脸、后宫收集
- 女频：情感纠葛、身份逆袭、甜宠日常

### 2.3 角色档案
每个角色提取：
- 姓名、角色定位（主角/对手/导师/盟友）
- 性格特质（3-5个关键词）
- 称呼变化（不同身份下的称呼）
- 关系网络（与其他角色的关系）

### 2.4 冲突池
- 核心冲突：贯穿全文的主线矛盾
- 阶段冲突：每集/每章的局部矛盾
- 潜在冲突：可挖掘但未展开的矛盾

### 2.5 钩子库
- 悬念钩：未解之谜，吸引观众继续观看
- 反转钩：预期颠覆，制造惊喜
- 情感钩：情感共鸣点，建立观众连接
- 伏笔钩：埋下未来发展的线索

### 2.6 爽点兑现表
- 预期爽点：读者/观众期待看到的满足感
- 兑现方式：如何实现该爽点
- 兑现时机：在第几集兑现
- 兑现状态：已兑现/未兑现/部分兑现

## 3. 输出格式
分析结果以 JSON 格式输出，包含以上所有维度。
